# luqmaan.dev

Personal site built with Astro 6. Run `pnpm dev` to develop and `pnpm build` to build.

## Skills

Use the **TypeSafe** skill (`typesafe-ai`, installed via the `typesafe@typesafe-ai` plugin
declared in `.claude/settings.json`) when working on this project. It covers building
AI-powered features as typed judgments (Choice, Noul, Score) and points at the live
docs at https://docs.typesafe.ai/llms.txt, which are the source of truth.
